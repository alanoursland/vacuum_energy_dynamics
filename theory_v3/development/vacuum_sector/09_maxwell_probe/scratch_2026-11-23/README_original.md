# VED Maxwell comparison scratch scripts
Use Python 3 with NumPy and SciPy. Run from the extracted directory. Place a checkout of alanoursland/vacuum_energy_dynamics at ./ved_read (a symlink also works); reference commit dc1d7aae3393f62be761e34d90997f176ffd3c76.
Run python cell_check.py, OPENBLAS_NUM_THREADS=1 python virial_check.py, then python mode_proxy.py. The second script writes Q80.npy, Q160.npy, Q320.npy for the third. eval_packing.py is the original packing-only variant, superseded by virial_check.py. Reference stdout files are included. These are exploratory scripts. The unsigned circumcentric distances in cell_check.py and mode_proxy.py were used for small perturbations around regular tetrahedra; do not reuse as general signed Hodge stars for arbitrary meshes.
