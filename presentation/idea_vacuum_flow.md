# Does creation know where the mass is?

The 045 seam is closed: expansion is creation, not stretch. That leaves one open dial — whether new space prefers to appear away from matter — stated as a formal clause with its dynamics still unknown.

## The idea

Once growth beats stretch (see [The Curvature Exchange →](idea_curvature_exchange.md) territory and the kill list below), the next question is where the new cells appear. The owner's founding intuition — long before it had a symbol — was that creation should be suppressed near mass: new space should show up preferentially *outside* wells, "pushed out" by whatever local strain a mass concentration represents.

The source file formalizes that intuition as a single suppression clause on the local creation rate:

```text
C = 3H(1 - alpha delta)
```

Read it term by term. `3H` is the background creation rate implied by growth-reading expansion (l fixed, N ~ a^3 — see the 045 kill list). `delta` is the local density contrast (the "am I in a well" variable). `alpha` is a single undetermined coefficient carrying all the physics of *how strongly* mass suppresses local creation.

Two things are already locked, with nothing left to tune:

- **Background invisibility, for any alpha.** Averaged over space, `<delta> = 0` by construction, so `<C> = 3H` regardless of what alpha turns out to be. The clause cannot be falsified by anything derived so far — not the Friedmann sector, not the floor's equation of state, not the G-constancy result. It sits underneath the entire theory as built and changes none of it.
- **Alpha is not yet computable.** The clause is a placeholder for a mechanism, not a mechanism. Making alpha a number requires the Lorentzian dynamics program (O-P10-4) — creation has to be derived as a functional of local strain, not asserted. Until then alpha is a free symbol and the clause makes no observable prediction.

This is what a formalized-but-undischarged idea looks like in this program: real object, real placement in the theory (it rides on the just-decided creation reading), zero claims yet. The node exists so the idea has an address — and so nobody mistakes "we wrote the suppression term down" for "we derived the suppression."
